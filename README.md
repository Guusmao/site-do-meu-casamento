# 💍 Site de Casamento - Felipe & Sarah

Um site de casamento elegante e responsivo desenvolvido para compartilhar os detalhes do grande dia de Felipe & Sarah.

## ✨ Funcionalidades

- ⏳ Contagem regressiva para o casamento
- ❤️ Seção "Nossa História"
- 📍 Informações da cerimônia e recepção
- 🖼️ Galeria de fotos
- 🎁 Lista de presentes
- 📋 Formulário de confirmação de presença (RSVP)
- 💌 Mural de recados para convidados
- 📱 Layout totalmente responsivo
- 🎨 Design moderno com animações suaves

## 🚀 Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/site-casamento.git
```

### 2. Entre na pasta do projeto

```bash
cd site-casamento
```

### 3. Abra o arquivo

Basta abrir o arquivo `index.html` em qualquer navegador moderno.

Ou utilize uma extensão como **Live Server** no VS Code para uma melhor experiência de desenvolvimento.

---

## ⚙️ Personalização

### Alterar os nomes dos noivos

No arquivo `index.html`, localize:

```html
<h1 class="hero-title">Felipe & Sarah</h1>
```

e substitua pelos nomes desejados.

---

### Alterar a data do casamento

No arquivo `app.js`, localize a variável da contagem regressiva e altere para a nova data:

```javascript
const weddingDate = new Date('2027-02-08T16:30:00');
```

---

### Alterar imagens

Substitua os arquivos dentro da pasta:

```text
assets/
```

mantendo os mesmos nomes ou atualizando os caminhos no HTML.
